# Accounts Period Balances managed model copy

This directory contains the LedgerExplorer-managed copy of the UADC-PoC Accounts Period Balances HMD. UADC-PoC is the model authority; the HMD bytes and SHA-256 must remain identical to its canonical copy.

The model was independently designed by the user with ISO 21378 used as a reference. It is not an ISO publication, is not an ISO-certified model, and does not include the ISO 21378 FDIS source.

LedgerExplorer does not use this HMD as a browser loader or report-generation dependency in the current release. It is supplied as model metadata accompanying the public synthetic dataset. The accepted technical validation is inherited from UADC-PoC and the managed-copy identity is verified separately.
